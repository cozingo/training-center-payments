# Мини-учёт оплат учебного центра

- `backend/` — REST API: Express, TypeScript, SQLite (better-sqlite3). Ученики, оплаты, отчёт «должники за месяц».
- `frontend/` — веб-страница для телефона: React, TypeScript, Vite. Список должников и форма добавления оплаты.

## Как запустить с нуля

Нужен Node.js 20.19 или новее (проверено на 24). Другие зависимости не нужны: SQLite встроен через `better-sqlite3`.

```bash
# 1. API — первый терминал
cd backend
npm install
npm run dev            # http://localhost:3000, база создаётся автоматически в backend/data.db

# 2. Фронтенд — второй терминал
cd frontend
npm install
npm run dev            # http://localhost:5173
```

Откройте http://localhost:5173. Чтобы открыть страницу с телефона, подключите его к той же Wi-Fi сети и зайдите по адресу `Network:` из вывода Vite. Фронтенд обращается к API через прокси Vite (`/api` → `localhost:3000`).

Чтобы добавить тестовых учеников (при запущенном API):

```bash
curl -X POST localhost:3000/students -H 'Content-Type: application/json' \
  -d '{"name":"Азиз Каримов","phone":"+998901234567","group":"English A1","monthlyFee":500000}'
curl -X POST localhost:3000/students/1/payments -H 'Content-Type: application/json' \
  -d '{"amount":200000,"date":"2026-10-05"}'
curl 'localhost:3000/debtors?month=2026-10'
```

Тесты и сборка:

```bash
cd backend  && npm test                     # e2e-тесты API (vitest + supertest, SQLite в памяти)
cd backend  && npm run build && npm start   # продакшен-сборка API (PORT, DB_PATH — переменные окружения)
cd frontend && npm run build                # статика в frontend/dist
```

Описание эндпоинтов — в [backend/README.md](backend/README.md), подробнее о фронтенде — в [frontend/README.md](frontend/README.md).

## Что бы я улучшил за ещё одну неделю

1. **История тарифов и периоды обучения.** Сейчас отчёт за прошлые месяцы считается по *текущей* месячной сумме: если поднять цену, у учеников появится «долг» за прошлые месяцы. Нужна таблица тарифов с датой начала действия, даты начала и окончания обучения (и паузы) вместо `created_at`. Ещё нужно решить, переносить ли переплату и долг на следующий месяц.
2. **Авторизация и роли.** Сейчас любой, у кого есть ссылка, видит телефоны учеников и может добавлять оплаты. Нужны вход для администраторов и роли (администратор или кассир).
3. **Исправление ошибок в оплатах.** Отмена и редактирование оплаты с журналом изменений (кто, когда, что поменял). Плюс поле «способ оплаты» (наличные, карта, Click/Payme) и, возможно, явный «месяц, за который оплата», а не только дата платежа.
4. **Тесты фронтенда и CI.** Playwright-тесты основного сценария на мобильном размере экрана, запуск тестов API и фронтенда в GitHub Actions на каждый PR, миграции БД вместо `CREATE TABLE IF NOT EXISTS`.
5. **Деплой.** Один Docker-образ, где API раздаёт собранный фронтенд с того же адреса (CORS не нужен), автоматические резервные копии файла SQLite и PWA-манифест, чтобы страницу можно было добавить на главный экран телефона.
